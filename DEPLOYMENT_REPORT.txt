【四、需要真实 API Key 的功能】
----------------------------------------------------------------------
⚠️ POST /chat (非流式): 需要 OPENAI_API_KEY 或对应提供商的 API Key
⚠️ POST /chat (流式 SSE): 需要真实 API Key
⚠️ WebSocket /ws/{sid}: 需要真实 API Key
⚠️ web_search 工具: 需要 TAVILY_API_KEY
⚠️ analyze_image 工具: 需要多模态模型 API Key
⚠️ run_python Docker 模式: 需要 Docker 镜像 python:3.11-slim
⚠️ CLI 交互模式: 需要真实 API Key 才能对话

   配置方法: 编辑 .env 文件，填入真实 API Key
   OPENAI_API_KEY=sk-your-real-key
   然后运行: neoagent 或 neoagent-server

【五、已知限制与注意事项】
----------------------------------------------------------------------
1. Docker 沙箱: 当前环境 Docker 可用，但需 python:3.11-slim 镜像
2. 调度器 list_tasks: APScheduler Job.next_run_time 属性兼容性问题
   - 不影响任务注册/触发，仅影响列表展示
3. Windows 路径: fileops 使用 realpath 解析，已验证跨平台安全
4. 成本计算: 基于模型目录的静态定价，实际成本可能因提供商变动
